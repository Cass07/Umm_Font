How to Use

빌드

seed로 난독화 폰트를 만든다. 원본 폰트를 지정하지 않으면 내장 Noto Sans KR을 쓴다.

from Umm_Font import build_font

build_font("my-seed", "out/umm.woff2")                     # 기본 Noto Sans KR
build_font("my-seed", "out/umm.woff2", "Pretendard.otf")   # 가진 폰트 지정 (TTF/OTF/가변)
python -m Umm_Font build --seed my-seed -o out/umm.woff2 [--font my.ttf]

암호화

한글 음절만 치환하고 나머지 문자는 그대로 둔다. 같은 원문도 매번 다른 암호문이 된다.

from Umm_Font import encrypt

enc = encrypt("my-seed", "가나 ABC")   # 예: '뎌\U000f1a2b ABC' (한글만 바뀜)
python -m Umm_Font encrypt --seed my-seed "가나 ABC"

복호화

같은 seed로 암호문을 원문으로 되돌린다.

from Umm_Font import decrypt

decrypt("my-seed", enc)                # '가나 ABC'
python -m Umm_Font decrypt --seed my-seed "<암호문>"
